
Estamos no MVP 0.2 — Integração real do cad-tools com apps/web.

Estado atual:
O apps/web já possui um MVP funcional com Canvas, grid, zoom, pan, Line, Select, Clear, Export JSON, Import JSON, Delete e command line.
O pacote cad-tools já possui ferramentas reais SelectTool, LineTool e EraseTool implementadas e testadas.
Porém o apps/web ainda usa lógica interna própria para algumas ações.

Tarefa:
Refatore o apps/web para integrar as ferramentas reais do pacote packages/cad-tools.

Objetivo:
O React deve apenas capturar eventos de UI e encaminhar para a camada de ferramentas.
A lógica de ferramenta deve ficar em cad-tools.

Implemente:

1. Criar um adaptador no apps/web para conectar eventos do Canvas com cad-tools.
2. Criar ou ajustar um ToolManager/ToolController no apps/web, caso ainda não exista.
3. Usar ToolRegistry do cad-tools para ativar ferramentas por botão ou command line.
4. Integrar SelectTool real.
5. Integrar LineTool real.
6. Integrar EraseTool real.
7. Manter funcionamento atual de:

   * grid;
   * zoom;
   * pan;
   * preview da linha;
   * seleção de linha;
   * Delete;
   * Export JSON;
   * Import JSON;
   * localStorage;
   * command line.
8. Remover ou isolar lógica duplicada de ferramenta dentro de useCadStore.ts e CadCanvas.tsx.
9. Manter adaptadores temporários apenas se cad-core ou cad-renderer ainda não tiverem contratos definitivos.
10. Adicionar TODOs claros onde houver adaptação temporária.

Regras:

* Não implementar backend.
* Não implementar login.
* Não implementar multiempresa.
* Não implementar novas ferramentas ainda.
* Não quebrar o MVP atual.
* Não colocar lógica geométrica pesada em componentes React.
* Não deixar CadCanvas decidir regras de ferramenta.
* CadCanvas deve encaminhar pointer events e keyboard events para a ferramenta ativa.
* A ferramenta ativa deve retornar preview, comando, mensagem, cancel ou complete.
* O renderer deve continuar responsável por desenhar.

Critérios de aceite:

1. npm run dev continua funcionando.
2. O usuário consegue desenhar linhas.
3. O usuário consegue selecionar linhas.
4. O usuário consegue apagar linhas com Delete.
5. Export JSON continua funcionando.
6. Import JSON continua funcionando.
7. Command line aceita line, select, erase, pan e clear.
8. Não há regressão visual no canvas.
9. Testes existentes continuam passando.
10. A arquitetura fica mais próxima do fluxo:
    apps/web → cad-tools → cad-core/document → cad-renderer.

Ao final, explique:

* quais arquivos foram alterados;
* quais lógicas foram movidas ou substituídas;
* o que ainda ficou como adaptador temporário;
* como testar manualmente;
* próximos passos recomendados.
